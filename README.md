# CineVerse 3.0 — Neon Revolution

Website giới thiệu phim theo phong cách Cyberpunk, dùng HTML/CSS/JavaScript thuần.

## Chạy thử

Mở toàn bộ thư mục dự án trong VS Code, sau đó chạy `index.html` bằng Live Server.
Không cần `npm install` hoặc `npm run dev`.

## Đưa lên GitHub Pages

Sao chép `index.html`, thư mục `css` và thư mục `js` vào **gốc** repository `KhangLN11.github.io`.
Sau khi kiểm tra, commit và push lên nhánh `main`; GitHub Pages chọn source `main` / `(root)`.

## Hình ảnh

Demo sử dụng đường dẫn poster từ TMDB. Poster cần Internet và có thể thay đổi theo thời gian. Nếu ảnh không tải, trang hiển thị nền gradient và tiêu đề thay thế. Trước khi công bố, hãy kiểm tra điều kiện sử dụng hình ảnh và nguồn phù hợp.

Không dùng backend, API key hay phát phim.
